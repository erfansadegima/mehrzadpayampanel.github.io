# CRM SMS Sender

نسخه اولیه وب‌اپ قابل نصب روی اندروید برای واردکردن Excel و آماده‌سازی پیامک‌ها.

## اجرا
1. فایل‌های این پوشه را روی یک هاست HTTPS یا GitHub Pages قرار دهید.
2. لینک `index.html` را با Chrome اندروید باز کنید.
3. از منوی Chrome گزینه **Add to Home screen / افزودن به صفحه اصلی** را بزنید.
4. اینترنت برای بارگذاری اولیه کتابخانه Excel لازم است.
5. فایل XLSX را انتخاب کنید، برگه و ستون شماره موبایل را مشخص کنید و متن پیام را بنویسید.
6. برای هر مخاطب «باز کردن برنامه پیامک» را بزنید، در برنامه پیامک خودتان ارسال کنید، سپس به اپ برگردید و «ارسال شد؛ بعدی» را بزنید.

## محدودیت‌ها
- این نسخه APK بومی نیست؛ یک وب‌اپ قابل افزودن به صفحه اصلی است.
- شماره‌ها فقط در مرورگر دستگاه پردازش می‌شوند و آپلود نمی‌شوند.
- به علت محدودیت‌های اندروید، ارسال نهایی باید در برنامه پیامک و با اقدام کاربر انجام شود.
- وضعیت ارسال/تحویل از اپراتور خوانده نمی‌شود؛ ثبت آن دستی است.
- شماره‌های استاندارد ایران (09xxxxxxxxx) و شماره‌های بین‌المللی دارای + پشتیبانی می‌شوند.
